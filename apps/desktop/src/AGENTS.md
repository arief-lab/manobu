## Local Contracts

This file is a **thin pointer** (DOX canonical-per-subtree rule — see
root `AGENTS.md` § Canonical-per-subtree). The canonical doc for this
subtree is **`../AGENTS.md`** (`apps/desktop/AGENTS.md`), which owns
the full local contracts, the SCR-01..SCR-12 catalog, the per-route
loader/validateSearch/loaderDeps audit table (TASK-25.1), and the
`lib/` / `components/` / `routes/` child index with the task-23.2.1 +
23.2 + 25.2 changes. **Read that file for the full contract; this file
only documents the local / sub-subtree bits that don't fit there.**

- Entry points
  - `main.tsx` — creates `QueryClient` (`lib/query-client.ts`) and mounts `<QueryClientProvider>` → `<RouterProvider>` over `routeTree.gen.ts` (auto-generated by `@tanstack/router-plugin`; do not edit by hand); `ReactQueryDevtools` gated on `import.meta.env.DEV`.
  - `index.css` — global styles (delegates to `@manobu/ui/globals.css` tokens) plus the `@source` lines `globals.css` cannot carry: the streamdown dist and `packages/chat-session/src` (that package renders its own Tailwind classes, and `globals.css` scans `apps/**` + `packages/ui/**` only — TASK-87). A new shared package that ships JSX with utility classes needs a line here, or its styles appear only by coincidence. Full audit (TASK-89, 2026-09-21): the ONLY packages shipping JSX utility classes are `packages/ui` (covered by `globals.css` `../**`) and `packages/chat-session` (covered by the line above); `agent`/`skills`/`speech`/`acp`/`api-contract`/`db`/`env`/`japanese`/`srs`/`config` ship no `.tsx` and no `className`/`class=`/`cn(`, so they need no line. `desktop` is the only CSS-consuming app (`server` is a JSON API), so this one `index.css` is the single place to add lines. A companion `@source not ".../*.test.{ts,tsx}"` line keeps chat-session test files out of that scan: Tailwind's scanner is lexical, so fixture strings like `msg_id: "start-1"` in `chat-engine-golden.test.ts` would otherwise emit dead utility rules into the bundle.
- Path aliases (from `apps/desktop/tsconfig.json`)
  - `@/*` → `./src/*`
  - `@manobu/ui/*` → `../../packages/ui/src/*`
- Generated
  - `routeTree.gen.ts` — regenerated by the Vite plugin on file changes; checked into git for deterministic builds.
- Children not exposed in this index
  - `main.tsx`, `index.css`, `routeTree.gen.ts` — entry/generated files; their rules live in the canonical `apps/desktop/AGENTS.md` and the relevant tooling docs.

## Work Guidance

- React/Next.js performance patterns: `.agents/skills/vercel-react-best-practices/SKILL.md`.
- shadcn rules (composition, forms, icons, chat, styling): `.agents/skills/shadcn/SKILL.md`.

- TanStack Query (`@tanstack/react-query`): `.agents/skills/tanstack-query/SKILL.md` — use `queryOptions` + `useQuery`/`useMutation` with hierarchical keys, `signal`, `enabled`, `staleTime`/`gcTime`, `networkMode: "offlineFirst"` for Tauri invokes; expose options for `queryClient.ensureQueryData` loaders.
- TanStack Router (`@tanstack/react-router`): `.agents/skills/tanstack-router/SKILL.md` — `RouterAppContext` + loaders + `validateSearch` + `notFoundComponent` + lazy splitting via the vite plugin's `autoCodeSplitting` (TASK-71.1: hand-written `.lazy.tsx` is banned — `route-loaders.test.ts` guards it).
- TanStack Form (`@tanstack/react-form`): `.agents/skills/tanstack-form/SKILL.md` — `useForm` + `form.Field` with `validators` (`onChange`/`onBlur`), `handleBlur`/`handleSubmit` (`preventDefault`/`stopPropagation`), `form.Subscribe` selectors (`canSubmit`/`isSubmitting`), `formOptions` reuse, Zod schemas, `aria-invalid` + live regions.
- Add new routes: file goes in `src/routes/<name>.tsx` (the chrome-free desk family — /setup, /dashboard, /lesson, /reader, /roleplay, /drill, /conjugate, /listen, /kanji, /settings, /review, /ai, /chat/history, /exam — lives at the top level and carries its own `←` bar; `__root.tsx`'s `CHROME_FREE_PATHS` decides the chrome, with prefix branches for parameterized descendants; the `/learn` layout is retired (router audit 2026-09-14) — only legacy redirect stubs + `learn/conversation/$sessionId` keep `/learn/*` paths) (with `validateSearch` + `loader` + `loaderDeps` + `pending/error/notFound` as needed; laziness is automatic — `autoCodeSplitting` hoists the components into their own chunk, never hand-write a `.lazy.tsx`), import the matching compound from `src/features/`, and re-run `bun run dev` to regenerate `routeTree.gen.ts` (restart the dev server after DELETING a route file — the plugin's watcher can miss removals and leave the generated tree referencing the old parent). The per-route loader audit table + the regression guard (`test/route-loaders.test.ts`) lives in `apps/desktop/AGENTS.md` — new routes should match that table.
