## 0. TL;DR — What AionUi has that manobu should actually steal (not clone)

AionUi wins because it treats **five product surfaces as one Cowork OS**, not five chat toggles: `Built-in Agent (zero setup) + Multi-Agent (auto-detect 20+ CLIs) + Team (Leader→Teammates via Team MCP) + Scheduled Tasks (cron as daemon) + 21 Assistants × 3-tier Skills as markdown per-conversation`. Each maps to a concrete gap where manobu's Teacher AI is still **single-agent, keyword-routed, inline-prompt, session-per-app**:

| AionUi surface | Manobu today | Benefit if adopted | Priority |

## 2. AI feature / workflow gaps — what to add (ranked)

### P0 — must, because AionUi proves "chat ≠ Cowork" without them

#### A. Per-conversation ACP session pool + Command Queue + Busy/Error taxonomy (Team needs this)

* **Today:** `apps/server/src/index.ts` holds a **single module-level `AcpModelResource`** for all `/ai` + `/learn/chat` requests (warm-TTFT optimization). Switching agent = restart server with different `ACP_AGENT_BIN`; rapid two sends can overlap on one `connection` and surf as opaque `throw Error`.
* **Want:** `AionUi docs/4.2 V2 Three-Layer` (`Infrastructure: ShellBuilder+Stdio::piped → Session: state machine → Application: useAcpMessage`) + `Connection Layer AcpConnection JSON-RPC` on our side: `Registry` (`AionUi agent_servers JSON` ↔ `registry.ts AgentSpec` `transport acp|direct-cli`) → `AcpAgentManager` (per-conversation `SessionStore {threadId → AcpThread}` `ref_count`) → `AcpAgent (transformMessage)` → `AcpConnection (npx stdio)` . Mapping in `doc-1 §3.2` + `agent-stack-gaps.md §Tier 1 ✅ vs Tier 2.2 Partial`.
* **Wiring:** Replace `let acp` with `Map<conversationId, AcpModelResource>` `LRU 3` (`AionUi's AcpRuntime`), re-target on `body.agent` change (`agent-switching-like-aionui §4 Tier A` session pool `Map<agentId, AcpModelResource>`). Port `classifyConversationBusyError` + `useConversationCommandQueue` `auto-drain on idle` (`AionUi platforms/conversationBusyError.ts` analog) + `buildSendFailureError {reconnect_agent|wait|fix_path|retry}` (`AionUi 4.2 §Error Handling` 4 codes: `USER_AGENT_DISCONNECTED, AIONUI_CONVERSATION_BUSY…`). Keep `Chat-state persisted to localStorage manobu:chat:v1` (`AGENTS.md`). **Effort ~80-120 lines** (`packages/acp/src` new files + small `apps/server/src/index.ts` edit) per `agent-stack-gaps §Tier 2.2 80 lines`.
* **Benefit:** Agent switching at runtime **and** mid-conversation without losing `amo_Fsrs revlog` `1..3/4 scale + FSRS params 21` + allows `Team Mode` to fan out (below).

#### B. Assistants as markdown + Skills as per-conversation toggle (the `assistants as markdown` identity vs engine split)

* **Today:** `apps/server/src/sensei-prompt.ts` is a `TS` constant (`agent-switching-like-aionui §2.2 The gap`); `packages/skills` already validates `zod frontmatter name/description/agent` `Resolution order: node_modules → .manobu/skills → ~/.manobu/skills` (`packages/skills/AGENTS.md:12`) and is tested (`6/6 bun`), but `systemPromptFor(agent, skills)` never reaches the header/overlay as a picker. Model dropdown polls `GET /agents/:id/models` (`AGENTS.md: /ai header pickers agent|persona|model hidden for kilo`) — no `session/update` SSE `available_commands` forwarder.
* **Want:** `AionUi 4.8-assistant-presets-and-skills` `assistants/hello-assistant-context.md` (whole file **is** system prompt) `→ contributes/assistants.json presetAgentType` bind → `assistantTypes.ts` `Assistant {id, agent, agent_status, enabled_skills, context, prompts, models}` + `AssistantDefaults {model,permission,thought_level,skills,mcps}` + 3-tier skills (`pptx/docx/pdf/xlsx/mermaid`; custom; Extension) with `skill indicator` per conversation `search/exclude` (chat header). *Do not* bring PPT factory `OfficeCLI` itself — bring the **packaging** (skill file → `Tool` subset per conversation).
* **Wiring:** Keep `AgentSpec` in TS (spawn is code — `agent-switching-like-aionui §TL;DR "There is no real difference in power — both are config"`) **but move personas to `assistant/*.md`** (`sensei.md` migrated verbatim from `sensei-prompt.ts`, plus `keigo-san.md` `sempai.md`, `eju-kaikan.md` etc.) as `doc-1 §4 Tier A/B` already plans (`assistants as markdown property without giving up TS safety`). Implement Tier A `GET /agents` → `listAgentCandidates()` + `installed: bool` (`agent_status missing/online/offline/unchecked` stylized dot) and `/ai body {agent?, assistant?}` (`Route useSearch`, `validateSearch`), header `AcpModelSelector`-style `null → disabled / no available_models → read-only / available → dropdown` (`AionUi 4.3 AcpModelSelector.tsx` 3 states) and Tier B `assistant/` loader (`SENSEI_SYSTEM_PROMPT deleted → loader`).
* **Benefit:** Community-editable personas, non-programmer translation packs, `per-skill Tool` narrowing (`KanjiTutor` loads KanjiVG `kvg:`-prefixed tool, `GrammarExplainer` loads `conjugate_verb`, `EJU Science` loads `lookup_eju_syllabus`) — cheaper context and less tool-choice hallucination; `HUMAN 3.0 Coach` style per-skill toggling maps to manobu's four-sub-agent router without code reload.

#### C. Cron — Scheduled auto-creation of JLPT/EJU practice (AionUi's moat over Claude Cowork)

* **Today:** Mocks are manual (`jlpt-mock` `Timer → Submit → Plan`), review relies on `Due aria-live=polite` polling on open (`dashboard dueCount`) + `nudge 1/day max`. `doc-1 §Relevance Table` lists the learner jobs: `FSRS due nudge, weekly JLPT mock, nightly weak-pattern → quiz rebuild, daily shadowing (TASK-21.5 Zipformer)`. None is scheduled.
* **Want:** `Scheduled Tasks — Cowork on Autopilot` (`readme Scheduled Tasks`): `Natural Language + 3 scheduling modes (cron expr with tz Asia/Shanghai + Every N min/h + One-time)` + `AI-created via /cron skill during conversation` + `2 execution modes (Continue in existing conversation keeps history vs Create new each time independent)` + `bindings: model/workspace/retention per task` + `keepAwake prevents sleep + missed detect after wake` + `queue protection skip if previous still running`.
* **Wiring:** `doc-1 §5.2.2 Tier B` `packages/cron` `ICronJob {id, prompt, cronExpr|interval|oneTime, tz, workspace, agent, model, executionMode, enabled, keepAwake}` `app_data_dir/cron/jobs.json` + `cronUtils parseCronExpr/parseCustomSchedule` + `repairCronJobTimeZone Int'l` + `ipcBridge.cron.*` analog `Tauri invoke cron_*` + `ScheduledTasksPage CreateTaskDialog presets Hourly/Daily/Weekly/Weekdays + Advanced raw cron` + `TaskDetailPage Run Now → 15s init poll → formatCronRunConversationTitle timestamp`. Ship 3 defaults disabled (`Morning review nudge 8:00 Asia/Tokyo continue`, `Weekly mock Mon 09:00 newConversation`, `Nightly weak-pattern every 360m`) — precisely `doc-1 §5.2.5 Amendment` `2 headless data-maintenance jobs` (`doc-3` `doc-2 P0 sqlite-vaporetto` ordering respected).
* **Benefit:** Only AionUi vs `Claude Cowork $100/mo macOS-only` table survives because `Cron 24/7 unattended` is not a nicer timer but an **unsupervised agent that writes `Revlog` entries** while the notebook sleeps — retention `>85%` (`nihongoai-spec-v1.md Measurement`) is schedule-driven. File-write side-effects (organize `Introduction.md`'d `smart classification`) reuse the same scheduler once the Teacher writes workbooks.

### P1 — should, before EJU N-levels look credible

#### D. Team Mode — parallel Teacher Agent (Leader → Conversation/ Kanji / Grammar / Vocab Teammates)

* **Today:** `Coordinator route` `packages/agent/src/subagents index.ts:22` `route(ctx) keyword regex` + `subagents {conversationCoachGrammarCheck (end punctuation) / grammarExplainerLookupPattern (substring n*.json) / kanjiTutorDecompose (CJK+kanji.json) / vocabSrsDueCards (previewIntervals d5/s10)}` executed **sequentially**; `Score weak 3 → Plan scaffold` is a `window.console.info` (`jlpt-mock.tsx:234`) not a delegated team.
* **Want:** `Team Mode — vm on each Teammate uses its own model via ACP (Leader: Claude, Teammate: Codex/Qwen…) while AionUi coordinates` + `Team-isolated workspace all read/write same folder, per-agent permission dialog with badge` (`Team Mode` section `AionUi_team.gif`). Mapping: `Leader = Coordinator`, `Teammates = 4 sub-agents` each as **separate ACP session** (its own backend, its own `unstable_setSessionModel`/`Tool` subset via assistant skill), **team-isolated workspace** (`content.db` `vocab_themes` + `app_data_dir/eju` stub) `file panel stays visible`, `Leader assigns/tracks/aggregates` through `Team MCP Server async mailbox + shared task board` (AionCore `packages/desktop/src/renderer/pages/team/TeamPage.tsx:85-88 warmupSession`).
* **Wiring:** Reuse Tier A session pool to hold `TeamRuntime {leaderSession, teammate[]}`: `warmupSession` per teammate, `file sharing: Leader can pass attachments`, `dynamic scaling: add/remove` while running, `silent auto-escalate failed + one-click removal`, `granular permissions sidebar badge`. * **Benefit:** One `Correct my conversation, teach grammar, show kanji stroke, adjust FSRS` request no longer **chooses** one sub-agent — it fans out in parallel under a shared workspace, cutting Teacher latency from `serial 4×` to `max-of-workers`. ## 5. Risks & guardrails

* **Don't rush Team before Tier A pool.** `Team` teammates each need an **isolated ACP session** + `own model` + `own permission dialog` (`Team Mode` `AionUi_team.gif` badge). Without `Map<convId,Resource> LRU3` + busy queue, teammates contend for the single `let acp`. **Order = doc-1 Tier A → D.**
* **Don't bring PPT factory for a language lab.** The 21-assistant list is tuned for **office** (PV for `Morph`, `Financial Model`, `3D Game`). Copying the whole list makes the sidebar `21` entries. Adopt **2 assistants** (`Sensei`, `KEIGO-Sensei`) + 2 skills (`mermaid radical graph`, `xlsx EJU chart`) via `Extension SDK` if at all — the big benefit per learner is **assistants as markdown**, not assistant count.
* **Don't bring 4 transports before the second MCP.** `Greed-sh ...` AionUi runs `AbstractMcpAgent` for `aionrs/remote + Claude/Qwen hybrid + stdio`. Your second server candidate is `crates/eju-mcp` (`doc-3`) or `doc-2` sentences — that's when `http/streamable_http` matters (`doc-1 §Out of scope` warned not to add `http` until then).
* **Don't turn file generation preview into a second Electron.** The `file_generation_preview.png` audience is quarterly-business-presentation. For a desktop where the `./wtf` channel weight is FSRS `desired_retention 0.90` (`settings.ts validateRetention 0.7-0.97`), the preview win is `Workbook Markdown → PDF` in `app_data_dir/workbooks/` `Preview` pane, not Office ribbon parity.
* **Don't confuse MCP with conversation memory.** `IMcpServer` tools are **stateless** tool calls (one `json→text`); `Continue in existing conversation` (cron's value) is **stateful** session memory. Cron's `Continue` needs `thread` persistence (`ThreadStore 80_000 token compaction` in Zed `ThreadStore`), MCP's single `page.navigate` does not. Keep them in separate `packages/cron` vs `packages/acp/mcp.ts`.
